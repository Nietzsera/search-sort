Visualisasi Interaktif Algoritma

Pilih salah satu algoritma di bawah ini untuk melihat cara kerjanya secara interaktif.

Bubble Sort

Mengurutkan data dengan menukar elemen yang berdekatan.

Insertion Sort

Mengurutkan data dengan menyisipkan elemen pada posisi yang tepat.

Linear Search

Mencari data secara berurutan dari awal hingga akhir.

Binary Search

Mencari data pada array terurut dengan membagi dua wilayah.
